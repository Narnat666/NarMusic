# NarMusic 1.0.0 安装说明（安卓 14 / vivo S60）

安装包：`NarMusic-v1.0.0.apk`（3,373,089 字节，已签名，`targetSdk 34`，支持 Android 8.0 及以上）。

## 1. 把 APK 传到手机

任选一种：

- QQ / 微信「文件传输助手」发给自己，在手机上点开；
- 数据线连电脑，把 APK 拖进手机任意目录（如 `内部存储/Download/`）；
- `adb install NarMusic-v1.0.0.apk`（手机开 USB 调试时）。

## 2. 允许安装「未知来源」应用

vivo（FuntouchOS / OriginOS，Android 14）：

1. 用「文件管理」找到 `NarMusic-v1.0.0.apk`，点它；
2. 首次会提示「禁止安装未知来源应用」→ 点「设置」→ 打开 **允许安装此来源的应用**（vivo 上一般名为「安装未知应用」）；
3. 返回，点「安装」；如果弹出「风险提示 / 应用未经安全检测」，选「继续安装」；
4. 如被「vivo 应用安全检测」拦下，可在 **设置 → 应用 → 应用安装管理** 里关闭「安装前安全检测」后重试。

## 3. 权限说明

装好后**不需要手动授权任何运行时权限就能用**（下载、入库、播放、删除都已在模拟器上验证过「未授权」状态可用）：

| 权限 | 实际行为 |
|---|---|
| 存储写入 | 不需要。文件通过 MediaStore 写入 `Music/NarMusic`，`targetSdk 34` 下无需存储权限 |
| 音乐和音频（READ_MEDIA_AUDIO） | App 不主动申请。自己创建的文件自己可读，库列表与播放不依赖它 |
| 通知（POST_NOTIFICATIONS） | App 不主动申请。下载在前台界面完成，没有常驻通知，因此不弹窗 |
| 网络（INTERNET） | 安装即授予，无需操作 |

如果系统在 vivo 上单独提醒「NarMusic 可能在后台耗电」，允许即可（不影响功能，只是省电策略）。

## 4. 音乐文件保存在哪

```
内部存储/Music/NarMusic/
```

文件名取自「自定义文件名（歌词提取）」，扩展名 `.m4a`，封面与歌词（`©nam/©ART/©alb/©lyr/covr`）已写进文件标签，可用任意播放器直接播放并显示歌词。

- 用系统「文件管理」→ 手机存储 → `Music` → `NarMusic` 可看到；
- 连电脑以「文件传输（MTP）」模式，进入 `内部存储/Music/NarMusic` 复制出来即可；
- 同一首歌重复下载会替换旧文件（旧文件按 MediaStore 删除），目录里始终只保留一份，不会累积同名文件。

## 5. 常见问题

**Q: 粘贴了 B 站分享文本（含 `b23.tv` 短链），会不会下错歌？**
- 不会。App 会先跟随短链跳转，定位到你分享的那一个视频再下载。完整的 `bilibili.com/video/BVxxx` 链接、`av` 号链接、单独粘贴 BV 号都可以。
- 只有输入里**完全没有链接**时才会当成关键词去 B 站搜索（取播放量最高的一条）。

**Q: 下载一直失败，提示「音频下载失败」/「获取视频信息失败」**
- 「获取视频信息失败」= 链接/接口问题：检查链接是否有效（视频被删、需登录、地区限制都会失败），或换关键词搜索。
- 「短链解析失败」= 该短链跳转不到视频页（链接过期或被平台改写），换成完整链接即可。
- 「音频下载失败」= CDN 拒绝：App 会依次用 `okhttp`、桌面 Chrome 两种 UA 重试所有音频节点，一般能成功；仍失败多为该视频全部节点限制，换个视频源试试。网络不好时先确认手机能正常打开 B 站。

**Q: 界面在横屏下能用吗？**
- 可以。横屏时导航会自动变成左侧竖排，内容居中限宽；播放器变成左右双栏（左封面与控件、右歌词）。旋转屏幕时正在输入的链接不会丢。

**Q: 歌词空了 / 歌词不对**
- 歌词按「歌名 - 歌手」去酷狗/网易云/QQ/汽水匹配，歌名与音频标题不一致就会匹配不到；把「自定义文件名」写成 `歌名 - 歌手` 格式（如 `稻香 - 周杰伦`）命中率最高。
- 汽水音乐只能用「含 `track_id=` 的汽水分享链接」命中，普通关键词搜不到。
- 想整体提前/延后歌词，去 设置 → 延迟 (ms) 填正负毫秒数再重新下载。

**Q: 删除歌曲时弹出系统授权框**
- Android 14 下 App 只能直接删自己创建的文件。若文件被其他应用/电脑重新写入过，删除会拉起系统「允许删除此文件吗」弹窗，点「允许」即可。

**Q: 装完打开闪退 / 白屏**
- 确认系统是 Android 8.0 以上；到 **设置 → 应用 → NarMusic → 存储 → 清除数据** 再打开；仍不行把 `adb logcat -s AndroidRuntime:E` 的输出反馈过来。

**Q: 装了旧版本想升级**
- 直接用同一签名的新 APK 覆盖安装即可（数据保留）。如果提示「签名不一致」，说明之前装的是别的来源的包，需先卸载旧版（会丢歌库记录，但 `Music/NarMusic` 里的文件不会删）。
